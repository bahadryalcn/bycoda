# Today

Open **Settings → Account**. "Activity on this computer" shows what you did in bycoda on this computer, for today or the current week (Monday to now): sessions touched, agent run time, active time and cost as figures, agent run time by project as a ring, a bar chart (run time by day for the week, active time of the last 7 days for today) and a sortable table by project. It works signed out. Cost uses the same estimate as the Provider usage page and is API-equivalent, not a bill; a leading "≥" means some models have no known price. Projects in a locked group are hidden.

Everything stays on this computer.

## Summarize

Summarize asks your own provider (the default model you chose for text actions) to write a short log entry.

1. Press Summarize to see the exact request. By default it holds only project folder names, counts, durations and costs. "Include session titles" adds the titles of the sessions touched. Message content is never included.
2. Check the estimated cost shown under the request.
3. Press Send. Nothing is sent before that.
4. Press Save to daily note to keep the result in a note named "Daily summary" with the date; later saves the same day append to it. Save shows its pending state and accepts one write at a time. If it fails, the summary remains available to retry.

For a signed-in account, switching Account tabs retains the request preview, running summary and result until you leave the account screen or sign out.

"Active time" here counts this computer only. Your account's Active time page adds your other signed-in devices.
