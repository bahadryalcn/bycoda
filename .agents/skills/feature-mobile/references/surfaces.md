# Mobile entry map

All code paths are repository-root relative; mobile/ has its own Git identity and local rules. Re-enumerate exported routes and actual adapters before a broad change.

- `mobile/AGENTS.md`, `mobile/package.json` and local artifact rules: platform workflow, pinned tooling and check commands.
- `mobile/src/ui/tokens.ts` owns the pure black/white resting surfaces; `mobile/scripts/build-ui-theme.mjs` generates `mobile/src/global.css`. Preserve semantic selection/status colors and visible editable boundaries through the shared field, search, composer and Sheet facades. Segmented tabs use text weight/contrast, not decorative colored strips. `mobile/src/ui/theme-contrast.test.ts` checks reading contrast; `themed-styles.test.ts` checks mounted theme updates.
- `mobile/app/`: Expo route/layout exports, with `(tabs)`, project, session, manage, tools and legal route groups. Follow imported screen components rather than treating wrappers as complete surfaces; include pairing/onboarding when affected.
- `mobile/src/ui/primitives.tsx`, `mobile/src/ui/chat.tsx` and focused shared UI modules expose product facades; `mobile/src/ui/panelui.ts` supplies PanelUI integration. Keep one scroll owner and safe-area/keyboard treatment through nested layouts.
- `mobile/src/remote/transport.ts` exports the public transport surface; `host-transport.ts` in that directory owns Host requests, transport selection and stream consumers. `ws-connection.ts` validates WebSocket envelopes and distinguishes RPC rejection from socket/protocol failure; `transport-validation.ts` validates endpoints and Host descriptors. `lan-fetch.ts` owns the encrypted HTTP LAN compatibility path.
- `mobile/src/state/host-runtime.ts` owns app-scoped native WebSocket leases and reconnect lifecycle; `mobile/src/state/queries.ts` owns access-aware query/mutation integration. `mobile/modules/bycoda-host-socket/` owns native socket implementations. Inspect these separately from HTTP compatibility transport.
- `mobile/src/domain/sessionSync.ts`, `mobile/src/domain/session-authority.ts`, `mobile/src/domain/approval-command.ts`: sync, source authority and approval identity. Compatibility workspace producers still need separate caller inspection.
- Workspace collection owners: `mobile/src/features/workspace/projects-screen.tsx`, `active-sessions-screen.tsx`, `project-screen.tsx` and `sessions-panel.tsx`. `session-project-row.tsx` owns global Sessions project headers; `session-list-feedback.ts` recognizes matching transient connection failures without merging distinct error recovery. Project aliases retain their Host IDs through `project-directory.ts`.
- `mobile/src/features/workspace/session-list-row.tsx` is the shared global/project conversation row. Preserve its full accessible identity, separate navigation/overflow targets, provider icon, pin, branch and truthful status. `src/features/connections/model/protocol.ts` defines `HostSessionSummary`; inspect the actual projection in `host/store.ts` before adding time or completion claims to mobile details.
- `mobile/src/features/workspace/session-row-actions.tsx` owns row action sheets and details; `session-row-action-model.ts` captures the displayed authority and checks a fresh session before `sessions.update`/`sessions.delete`. `mobile/src/ui/swipe-actions.tsx` adapts PanelUI reveal gestures without full-swipe execution. Keep the overflow path equivalent and deletion separately confirmed.
- Row writes reuse `mobile/src/state/connection-scope.ts`, `reviewed-machine.ts`, `queries.ts` and the existing project visibility callback. Check `host/server.ts` and `host/store.ts` for the actual metadata/delete semantics: deletion rejects live runs and may await desktop-owned deletion; it has no expected-revision compare-and-swap or command-receipt contract. Do not infer safe replay from an interrupted response.
- `mobile/src/features/workspace/project-screen.tsx` owns the single title action group and combined project/session menu; `sessions-panel.tsx` supplies guarded session actions and retains the query while search is collapsed. Native stack headers and the shared heading fallback must expose the same actions without duplicating a toolbar.
- Project identity uses `mobile/src/ui/brand.tsx` for the monochrome mark beside the current project title. `mobile/src/ui/machine-bar.tsx` supplies exceptional connection feedback from its existing health owner; healthy status renders no row. Preserve checking/unknown, offline and access failures as distinct states through `connection-presentation.ts`.
- Chat entry and composition: `mobile/src/features/workspace/session-screen.tsx`, `session-composer.tsx` and their existing transcript owners. Keep the requested four workspace surfaces compact without changing unrelated route families.
- `mobile/src/features/workspace/`: conversation state, composer, transcript, tool previews and active Host transport producers. Search `use-composer-catalog`, `transcript-tool-preview`, `transcript-block` and actual approval producers when changing those features.
- Host/mobile RPC families are defined by the active client and Host schema, not this map. Search exact `sessions`, `workspace.run`, `projects`, `models`, `tasks`, `goals`, `crews`, `notes`, `inbox`, `browser`, `devices`, `logs` and development-server call sites only as relevant; inspect compatibility paths as separate producers.
- Desktop pairing/access wiring: `src/features/connections/`, native remote/local-Host adapters in `src-tauri/src/`, corresponding authenticated handlers in `host/`. Follow the existing credential owner instead of putting bearer material in renderer state.
- Native mobile inline-render capability, SSH/PTY and external session-link launch are distinct from desktop implementations; inspect actual platform support before offering controls.
- Locate locale catalogs and tests from `mobile/package.json` and `mobile/src/`; search affected visible labels, operation names and translated state copy. Run normal nested typecheck plus focused affected suites, then the appropriate simulator/physical-device/live-Host scenarios.
- Focused connection regression owners include `mobile/src/remote/ws-connection.test.ts`, `host-transport-ws.test.ts` and `transport.test.ts`, plus `mobile/src/state/host-runtime.test.ts`. Collection coverage includes workspace `project-directory.test.ts`, `session-directory.test.ts`, `session-collection.test.ts` and `session-list-feedback.test.ts`.

For cross-platform authority, refer to repository-root `docs/reference/host-runtime.md`; for workspace identity and capability gates, `docs/reference/managed-workspaces.md`. Prior route counts, captured external HEADs and old read-only grants are historical evidence, not current capabilities or authorization.
