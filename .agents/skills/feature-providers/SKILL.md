before startup. Cleanup retains the actual handle and its original kill callback,
not a later session-name lookup. Failed and unknown originals survive Live-map

visibility and account entitlement. Last model deliberately remains on; modelsFor
falls back to catalog on all-off. Explain it and provide a coherent provider-hide
path. Any new empty-enabled policy requires all consumers changed together.

Catalog failures retain useful bundled/old data; expose source/freshness/error,
not false availability. Local hidden/disabled provider records are excluded by
discovery; toggles cannot bypass them. Host models.list remains authoritative for
remote sessions with capability gates. Mobile custom IDs/Host fallback exist;
desktop preference synchronization and mobile updater parity are not established.

Repair storage-error semantics for model/global/project defaults, project
provider/model inheritance reset, visible scope and account refresh ownership.
Preserve draft/selection and explicit unsaved/retry instead of cache-only success.
Keep account registration verification/serialization/duplicate rejection, abort/
temporary cleanup, stable identity/default/color/pins and removal confirmations
with running-turn consequences and retained history. Pending sign-in must not
disappear on provider navigation or survive an unowned Settings leave unnoticed.

CLI current-version checks and last operation outcome are separate. Fix stale
success masking a newer release and repeated success; distinguish actual version
verification from catalog refresh, whose errors currently get swallowed. Retain
checks during revalidation, dedupe/forced probe, per-harness update ownership and
real resolved-version verification. Dismissing notice leaves update running;
there is no cancellation API to invent. Preserve300s update/10s lookup timeout,
closed stdin, OpenCode migration/npm prefix and bounded4000-char failure output.
Binary modal callbacks need dismissal-generation ownership, keeping draft/error,
validation, focus and active-versus-configured-next/restart path distinction.

Owner-reported missing glyphs remain unconfirmed in installed pixels. Current
