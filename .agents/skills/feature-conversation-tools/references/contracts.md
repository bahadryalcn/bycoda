# Conversation control and transfer contracts

## Device admission and inspection

Input requires Host `controlProtocol: 1` and device-bound lease; viewing, inspection selection
and restored drafts never claim control. Retain request identity, expiry/revocation, competing
controllers and stale-node rejection. Inspect captures fresh tree then frame, never OS-atomic.
Preview picking needs verified pixel coordinates and matching dimensions; unknown scaling
stays list-only. Platform text limitations retain entered drafts. Browser/device annotations
bind exact captured frame, target and lease, independently of opening/booting a preview.

## Discovery and process lifecycle

Discovery filters by caller exposure, preserving legacy grants separately from effect/retry
metadata. `group` selects transport, `family` domain. Invalid options identify field/allowed
values without caller-input echo; numeric errors identify field/type/bounds. Schema and
service limits align, with defaults/cursor recovery documented. Project, cwd and machine
identity never collapse; availability does not grant control.

Keep listeners with unknown project association, bounded/redacted logs and samples,
process review/confirmation and partial-result truth. Process state needs exact owned
identity; unknown shutdown remains held. Target generations and cleanup reject stale
asynchronous results.

## Presentation and scoped browser state

Execution, frame evidence and mounted panel are separate preview results. Viewport change
invalidates annotations; duplicate request identity cannot renavigate. Dock follows active
canonical conversation. Detached presentation follows by default or pins without changing
composer ownership or browser leases; retain hidden drafts and stop hidden polling.
Native transfers require destination mount acknowledgement. Configured native window creation
retains main WebView2 environment options/data directory. URLs contain bounded presentation
metadata only, never draft text/image bytes; drafts use targeted events, never layout storage.

Browser contexts belong to canonical native sessions. Alternate-machine presentation needs
separate owner-scoped namespace and advertised support; unavailable support cannot use a shared
page. Same-target frames survive input; serialized input checks document/lease and rejects stale
results. Capture IDs/comments retain originating annotation scope. Inspection geometry persists
versioned/bounded; DOM node handles stay ephemeral. Traversal/layout overlays reject unsupported
or stale targets. Native/mobile transport remains independently owned and qualified.

## Draft transfer and recovery

Browser transfers carry capture references; other domains use bounded targeted native messages.
Retain capture/annotation/attachment drafts through navigation/failure and feed composer through
existing integration. ACK must match source, destination, conversation, tool and machine.
Uncertain transfers reuse immutable operation identity/payload, reconcile existing receipts,
and preserve both drafts when editable content changed. Initiating controls retain pending,
error/cancellation and cleanup; fixture success cannot prove native/physical-device acceptance.
