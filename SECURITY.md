# Security

Do not disclose vulnerabilities in public issues. Send bycoda vulnerability
reports privately to [info@bahadrhllyalcn.com](mailto:info@bahadrhllyalcn.com).
The [maintainer's profile](https://github.com/bahadryalcn) is available for general contact.

Include the affected commit or version, platform, and reproduction steps.
Do not include live credentials, access keys, or unrelated private session data.

bycoda runs installed agent CLIs. Agents can edit files and execute commands
within their granted permissions. Review project access, provider permissions,
and command approvals accordingly.

For vulnerabilities in the original application project, follow the
[upstream security policy](https://github.com/bahadryalcn/bycoda/blob/main/SECURITY.md).
Identify the affected repository and application version in your report.
