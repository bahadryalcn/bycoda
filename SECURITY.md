# Security

Do not disclose vulnerabilities in public issues. Send bycoda vulnerability
reports privately to [info@bahadrhllyalcn.com](mailto:info@bahadrhllyalcn.com).
The [maintainer's profile](https://github.com/bahadryalcn) is available for general contact.

Include the affected commit or version, platform, and reproduction steps.
Do not include live credentials, access keys, or unrelated private session data.

bycoda runs installed agent CLIs. Agents can edit files and execute commands
within their granted permissions. Review project access, provider permissions,
and command approvals accordingly.

This policy covers this bycoda repository and its desktop, Host and mobile
integration code. Identify the affected repository, component and application
version or commit. The latest published release and current source are the
primary investigation targets; report an issue in an older version as well if
you are unsure whether it persists. This is not a promise to maintain every
older release or a guaranteed response schedule.

Vulnerabilities in an installed provider CLI or another dependency may require
that project's private reporting process. Identify the dependency and version;
do not copy private reports to a public issue.
